# Instructions to build and run project locally

> [!IMPORTANT]
> ### Fetch project dependencies from [npm repository](https://www.npmjs.com/) before start
> For this action use simple command
> ```sh
> npm install
> ```

#### Add new dependency to project
By running previous command with name of dependency at the end
```sh
npm install name_of_dependency
```

#### Compiles and hot-reloads for development
Use next command, it will open a 8080 local port on your computer
```sh
npm run serve
```

#### Lints and fixes files
Use command to analyze your code for problems with logic and syntax  
```sh
npm run lint
```

#### Compiles and minifies for production
```sh
npm run build
```

#### Customize configuration
See [Configuration Reference](https://cli.vuejs.org/config/).
